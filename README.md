# Python for AI — University Lecture Deck

An interactive 28-slide university lecture presentation application for BSc Computer Engineering students (`ENG-CS-PYAI-101`), titled **"Python for AI: From Principles to Machine Learning"**.

## Features

- **Interactive Pedagogical Slide Deck**: 28 structured lecture slides covering the dual history of programming languages and artificial intelligence, culminating in Python convergence and machine learning.
- **Bilingual Lecturer Transcripts**: Integrated spoken notes with pedagogical tips and synchronized timings in both Indonesian and English.
- **Hardware-Level SIMD Simulation**: Live side-by-side benchmark comparing interpreted sequential Python loops with vectorized NumPy C-buffer SIMD execution.
- **Interactive Scikit-learn Playground**: Live editable Python code runner in the browser with real-time classification inference and celebratory visual cues.
- **Historical Milestones & Storytelling**: Visual timelines, card reveals, code snippet inspections, and interactive knowledge checks.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **Icons & Animations**: Lucide React, Motion (Framer Motion), Canvas-Confetti
- **Build Tool**: Vite

## Getting Started

1. Clone this repository
```bash
git clone <your-repository-url>
cd <repository-directory>
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```
